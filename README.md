# hr-multi-agent-milestone-3
milestone 3
To run the project following steps needs to follow
Step 1:create the .env file add gemini API key in .env file  APIkey for example GOOGLE_API_KEY="Paste your key here"
STEP 2: install dependencies python -m pip install langchain langchain-core langchain-google-genai python-dotenv  and pip show langchain-google-genai
STEP 3:create virtual environment and and run following command to activate the virtual environment .\venv\Scripts\Activate
STEP 4: run the program use this command python main.py
